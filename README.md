# RanasLocasPelea
El término "ranas locas" (o la rana loca) suele referirse principalmente a un personaje viral de internet, aunque también da nombre a juegos y contenido infantil:
• Crazy Frog (La Rana Loca): Es el famoso personaje animado en 3D creado por el sueco Erik Wernquist en 2003. Se hizo mundialmente conocido por el sonido imitando el motor de una motocicleta y por su exitosa versión eurodance del tema "Axel F".
• Juegos de mesa: Existen juguetes populares de destreza y equilibrio bajo este nombre (como Las 50 Ranas Locas o Ranas Saltarinas), donde los jugadores deben colocar ranitas sobre un árbol o plataforma sin que se caigan.
